# AutoBlur-NN ⚡️ AI自動ぼかし＆モザイクツール

**「280枚超をわずか18秒で完了。AIが瞬時に『性器のみ』を狙い撃つ爆速ツールを開発しました！」**

AutoBlur-NN は、画像フォルダ内に溜まった大量の画像からセンシティブな部位をAIで自動検知し、一括で滑らかな加工を施すデスクトップツールです。

## 🚀 AutoBlur-NN が選ばれる理由

### 1. 圧倒的な処理スピード
数百枚の画像スキャンから加工・保存までをわずか数十秒で完結。
手作業では何時間もかかる作業を、一瞬で終わらせる体験を提供します。

### 2. 「ペンで塗ったような」自然な仕上がり
従来の四角いモザイクではなく、**楕円形のマスクと境界線のぼかし（フェザー効果）**を採用。周囲の肌色とふんわり馴染むため、加工後の違和感を最小限に抑えます。

### 3. 性器のみをピンポイントでガード
AI（深層学習モデル）が各部位を正確に識別。「乳首はOK、性器のみNG」といった細かい設定も、チェックボックス一つで簡単にカスタマイズ可能です。

### 4. 100%ローカル実行・プライバシー重視
外部サーバーへの画像送信やAPI通信は一切ありません。オフライン環境でも動作するため、機密性の高い画像が外部に流出する心配はゼロです。

## � 使い方 (How to Use)

AutoBlur-NN の操作は非常にシンプルです。

1.  **フォルダを選択する**
    *   **Source Folder**: 処理したい画像が入っているフォルダを選択します。
    *   **Output Folder**: 加工後の保存先を指定します（デフォルトで `output` フォルダが作成されます）。
2.  **設定を調整する（お好みで）**
    *   **Sensitivity**: 検出の厳密さを調整します（通常はデフォルトの 0.20 でOK）。
    *   **Area Scale**: 加工範囲の広さを調整します。
    *   **Method**: 「モザイク」か「ぼかし」を選択します。
    *   **Exclude**: モザイクをかけたくない部位（胸部など）にチェックを入れます。
3.  **処理を開始する**
    *   「Start Processing」ボタンを押すと、爆速で処理が始まります。
    *   進捗バーが右端まで到達し、「Task finished」と表示されれば完了です！

## �🛠 技術スタック (Under the Hood)

本ツールは、信頼性の高いオープンソース技術を最適化して組み合わせています。

- **AI/ML (Computer Vision)**: [NudeNet](https://github.com/notAI-tech/NudeNet)
    - センシティブ画像を解析するための強力な学習済みモデルを使用。
- **Image Processing**: [OpenCV](https://opencv.org/)
    - C++ベースの超高速画像演算により、楕円形マスク処理とガウスぼかしをリアルタイムで適用。
- **GUI Engine**: [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)
    - ユーザーフレンドリーなダークモードUIと、マルチスレッド処理によるストレスのない操作感を実現。
- **Unicode Support**: 
    - 日本語を含むディレクトリパスやファイル名を安全に扱うための独自実装（NumPy/Binary I/O）。
